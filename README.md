# Detroit Scoreboard

A dashboard scoreboard that monitors selected teams and shows live game details.

## Links

- [Live scoreboard](https://burn56.github.io/detroit-scoreboard/)
- [Team builder](https://burn56.github.io/detroit-scoreboard/builder.html)

Use the builder to choose teams and generate a custom scoreboard URL. A custom `?teams=` configuration replaces the default team list.

## Previews
